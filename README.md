# E-Commerce-RFM-Customer-Segmentation-and-Cohort-Analysis
# 🛍️ Retail Sales Analysis using SQL & Excel Dashboard

## 📌 Project Overview

This project analyzes a retail sales dataset using **SQL** and presents key business insights through an **Excel dashboard**. The objective is to demonstrate SQL querying, business analytics, and dashboard creation by transforming raw transaction data into actionable insights.

---

## 🎯 Objectives

* Analyze retail sales performance.
* Calculate important business KPIs.
* Identify top-performing products and countries.
* Segment customers using **RFM Analysis**.
* Perform **Cohort Analysis** to understand customer retention.
* Visualize insights using an Excel dashboard.

---

## 🛠️ Tools & Technologies

* **SQL (SQLite)**
* **Microsoft Excel**
* Git & GitHub

---

## 📂 Dataset

The dataset contains retail transaction details, including:

* Invoice Number
* Product Code
* Product Description
* Quantity
* Invoice Date
* Unit Price
* Customer ID
* Country

---

## 📊 Key Performance Indicators (KPIs)

* Total Revenue
* Total Orders
* Total Customers
* Return Orders

---

## 📈 Analysis Performed

### 1. Data Cleaning

* Identified guest checkouts (missing Customer IDs)
* Identified return transactions
* Calculated Total Revenue for each transaction

### 2. Revenue Analysis

* Country-wise revenue
* Monthly revenue trend
* Product-wise revenue

### 3. Customer Analysis

* Guest vs Registered customers
* Top customers based on purchase value

### 4. RFM Analysis

Customers were segmented using:

* **Recency** – Days since the customer's last purchase
* **Frequency** – Number of purchases
* **Monetary** – Total amount spent

Customer segments include:

* Champions
* Loyal Customers
* Potential Loyalists

### 5. Cohort Analysis

Analyzed customer retention by grouping customers based on their first purchase month and tracking repeat purchases over time.

## 💡 Key Insights

* United Kingdom generated the highest revenue.
* Product revenue varied across different categories, highlighting top-performing products.
* Customer segmentation helped identify loyal and high-value customers.
* Monthly sales trends provided insights into seasonal performance.
* Return transactions were tracked to understand their impact on sales.
